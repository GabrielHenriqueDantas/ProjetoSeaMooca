# 🐟 Sea Mooca – Peixaria Online

Site oficial da **Sea Mooca**, uma peixaria localizada em [cidade/estado], dedicada a oferecer **peixes frescos e produtos de qualidade** diretamente para os clientes.  
Este projeto foi desenvolvido para exibir os produtos, receitas e informações de contato da peixaria de forma moderna e responsiva.

---

## 📝 Funcionalidades do site

- **Home:** Apresenta a peixaria, destaques e promoções.  
- **Peixes e Peixes Frescos:** Catálogo de produtos com imagens e descrições.  
- **Empório:** Itens adicionais disponíveis para venda.  
- **Receitas:** Sugestões de pratos utilizando os produtos da peixaria.  
- **Contato:** Informações para telefone, WhatsApp e endereço.  
- **Carrinho de Compras:**  
  - Cliente pode escolher produtos clicando neles e selecionar a quantidade desejada.  
  - Ao finalizar, o carrinho gera uma mensagem pré-escrita e redireciona para o WhatsApp para concluir a compra.  
- **Responsividade:** Layout adaptado para dispositivos móveis e desktops.  
- **Interatividade:** Clique em produtos para ver detalhes, preços e quantidade antes de adicionar ao carrinho.
